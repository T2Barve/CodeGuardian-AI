# Engineering Standards & Security Policies (RAG Knowledge Base)

This directory houses the ground-truth corporate engineering standards ingested into ChromaDB for retrieval-augmented agent reasoning:

- `security/`: Secure coding baselines (SQL injection prevention, crypto, secret handling).
- `coding-standards/`: Language-specific maintainability, complexity limits, and style guidelines.
- `testing/`: Unit and integration testing coverage criteria.
- `documentation/`: Public API documentation standards.
